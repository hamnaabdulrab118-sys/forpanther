# responsive split line border (1 element, autumn themed)

A Pen created on CodePen.

Original URL: [https://codepen.io/thebabydino/pen/PGapZM](https://codepen.io/thebabydino/pen/PGapZM).

Inspired by [this Pen](https://codepen.io/AllThingsSmitty/pen/bpYjPO/?editors=0100) and [article](http://allthingssmitty.com/2016/10/10/splitting-a-border-around-another-element/) by @AllThingsSmitty. My solution uses no extra elements for the split border, but a simple `repeat-x` `1px` tall gradient. The logo is created with the `::after` pseudo and the header background effect makes use of the `::before` pseudo
