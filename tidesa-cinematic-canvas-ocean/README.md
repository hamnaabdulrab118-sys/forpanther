# TIDES - A Cinematic Canvas Ocean

A Pen created on CodePen.

Original URL: [https://codepen.io/Chathura-Jayasanka/pen/emBMYWJ](https://codepen.io/Chathura-Jayasanka/pen/emBMYWJ).

A cinematic, photoreal ocean rendered entirely on HTML canvas with vanilla JavaScript,  just math, gradients, and light.

Drag the time-of-day slider to watch the entire scene morph through six 
moods: dawn → morning → midday → golden hour → sunset → moonlit night.  The sky, sun, water, foam, glitter, and stars all interpolate together in  real time.
